# Configuration examples

Start with the complete [TotalMarker template](../config/totalmarker.example.toml).
The recipes here illustrate cloud settings to transfer deliberately into your
ignored personal `config/totalmarker.toml`; they do not replace the complete
configuration or install anything. Supply your own permitted source/credentials,
and never commit personal URLs, tokens or passwords.

- [Xeric cloud settings](xeric.example.toml)
- [Custom cloud settings](custom.example.toml): replace the `.invalid` URL first.

Other native examples remain with their consumers:

- [Desktop definitions](../config/xp.def.example), [renderer configuration](../config/xp.conf.example), and [Earth configuration](../config/earth.example)
- [LaunchAgent templates](../scripts/launchd/): setup substitutes installation paths.
- [Configurator stock scenes](../docs/configurator/stock-scenes.md): open through the studio and save your own copy.

See the [documentation index](../docs/README.md) for setup and usage.
