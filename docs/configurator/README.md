# Xplanet scene studio

Configure and preview native Xplanet scenes, save a new copy, and explicitly
select an immutable revision for the next desktop start. The studio uses Python
3.11+ with isolated Textual dependencies; Xplanet performs the rendering.
Saving, selection and desktop restart are separate actions.
